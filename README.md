# Category C — Business Logic Coding Assignment

Beginner-friendly Java solutions for the five problems in the provided screenshots.

## Programs
1. `MovieTicketCounter.java` — calculates ticket prices and a shared convenience fee.
2. `ParcelShippingDesk.java` — calculates shipping charges and applicable insurance.
3. `CollegeFeeCounter.java` — calculates fees by student category.
4. `CityCabFareMeter.java` — calculates fares, minimum fare, and night service rules.
5. `HomeApplianceEnergyReport.java` — calculates energy usage and cost, including supported saver mode.

## Compile and run
Install a Java JDK. Open a terminal in this folder and run one program at a time, for example:

```text
javac MovieTicketCounter.java
java MovieTicketCounter
```

Use the corresponding filename and class name for the other programs.
